# 3.1 Logistic回归模型

## 什么是Logistic回归

Logistic回归是一种用于预测分类变量的监督学习算法，它虽然名为"回归"，但实际上是一种分类算法。Logistic回归的目标是通过输入特征预测样本属于某个类别的概率。

### Logistic回归的基本思想

Logistic回归通过Logistic函数（也称为Sigmoid函数）将线性模型的输出映射到[0,1]区间，从而得到样本属于正类的概率。

## Sigmoid函数

Sigmoid函数的数学表达式为：

$$ \sigma(z) = \frac{1}{1 + e^{-z}} $$

其中 $z = \mathbf{w}^T\mathbf{x} + b$ 是线性组合。

### Sigmoid函数的特点

- **取值范围**: (0, 1)
- **形状**: S形曲线
- **导数**: $\sigma'(z) = \sigma(z)(1 - \sigma(z))$，计算方便
- **当z=0时**: $\sigma(0) = 0.5$
- **当z→∞时**: $\sigma(z)→1$
- **当z→-∞时**: $\sigma(z)→0$

## Logistic回归模型的形式

对于二分类问题，Logistic回归模型可以表示为：

$$ P(y=1|\mathbf{x}) = \sigma(\mathbf{w}^T\mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T\mathbf{x} + b)}} $$

其中：
- $P(y=1|\mathbf{x})$ 是样本 $\mathbf{x}$ 属于正类的概率
- $\mathbf{w}$ 是权重向量
- $b$ 是偏置项

对于多分类问题，可以使用softmax函数扩展Logistic回归。

## Logistic回归的应用场景

Logistic回归广泛应用于以下场景：

1. **二分类问题**:
   - 垃圾邮件检测
   - 疾病诊断
   - 信用风险评估
   - 欺诈检测

2. **多分类问题**:
   - 手写数字识别
   - 图像分类
   - 情感分析

### 具体应用例子

- **垃圾邮件检测**: 预测邮件是否为垃圾邮件
- **疾病诊断**: 根据症状和检查结果预测患者是否患有某种疾病
- **信用评分**: 评估个人或企业的信用风险
- ** churn预测**: 预测客户是否会流失

## Logistic回归与线性回归的区别

| 特性 | 线性回归 | Logistic回归 |
|------|----------|-------------|
| 输出类型 | 连续值 | 概率值（0-1） |
| 模型形式 | $y = \mathbf{w}^T\mathbf{x} + b$ | $P(y=1|\mathbf{x}) = \sigma(\mathbf{w}^T\mathbf{x} + b)$ |
| 损失函数 | 均方误差 | 对数损失（交叉熵） |
| 应用场景 | 回归问题 | 分类问题 |
| 假设 | 线性关系 | 对数几率线性关系 |

## Logistic回归的优缺点

### 优点

- **简单高效**: 模型训练速度快，适合处理大规模数据
- **可解释性强**: 权重可以反映特征的重要性和方向
- **概率输出**: 提供样本属于各个类别的概率
- **易于正则化**: 可以添加L1或L2正则化项防止过拟合
- **适合作为基准模型**: 常被用作其他复杂模型的基准

### 缺点

- **线性决策边界**: 只能学习线性决策边界，对于非线性问题表现不佳
- **特征工程要求高**: 需要手动进行特征选择和转换
- **对异常值敏感**: 异常值会影响模型性能
- **假设独立性**: 假设特征之间相互独立，这在实际应用中往往不成立

## Logistic回归的决策边界

Logistic回归的决策边界是当 $P(y=1|\mathbf{x}) = 0.5$ 时的点集，即：

$$ \mathbf{w}^T\mathbf{x} + b = 0 $$

这是一个线性超平面，将特征空间分为两个区域：
- 当 $\mathbf{w}^T\mathbf{x} + b > 0$ 时，预测为正类
- 当 $\mathbf{w}^T\mathbf{x} + b < 0$ 时，预测为负类

## 正则化的Logistic回归

为了防止过拟合，Logistic回归也可以添加正则化项：

1. **L1正则化（LASSO）**:
   $$ J(\mathbf{w}, b) = -\sum_{i=1}^{n} [y_i\log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)] + \lambda\sum_{j=1}^{m} |w_j| $$

2. **L2正则化（Ridge）**:
   $$ J(\mathbf{w}, b) = -\sum_{i=1}^{n} [y_i\log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)] + \frac{\lambda}{2}\sum_{j=1}^{m} w_j^2 $$

其中 $\lambda$ 是正则化参数，控制正则化的强度。

## 小结

Logistic回归是一种强大的分类算法，它通过Sigmoid函数将线性模型的输出映射到概率空间，从而实现对分类问题的预测。Logistic回归简单高效，可解释性强，广泛应用于各种分类场景。虽然它只能学习线性决策边界，但通过特征工程和正则化技术，可以显著提高其性能。
