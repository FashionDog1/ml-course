# 2.1 线性回归简介

## 什么是线性回归

线性回归是一种用于预测连续值的监督学习算法，它假设输入特征与输出之间存在线性关系。线性回归的目标是找到一条最佳拟合直线（或超平面），使得预测值与实际值之间的误差最小化。

### 线性回归的基本形式

对于单变量线性回归，模型可以表示为：

$$ y = wx + b $$

其中：
- $y$ 是预测值
- $x$ 是输入特征
- $w$ 是权重（斜率）
- $b$ 是偏置（截距）

对于多变量线性回归，模型可以表示为：

$$ y = w_1x_1 + w_2x_2 + ... + w_nx_n + b $$

或使用向量形式：

$$ y = \mathbf{w}^T\mathbf{x} + b $$

其中：
- $\mathbf{w}$ 是权重向量
- $\mathbf{x}$ 是输入特征向量

## 线性回归的应用场景

线性回归是一种简单但强大的算法，广泛应用于以下场景：

1. **预测分析**: 预测房价、股票价格、销售额等连续值
2. **趋势分析**: 分析时间序列数据的趋势
3. **因果关系研究**: 探索变量之间的线性关系
4. **特征重要性评估**: 评估不同特征对预测结果的影响程度

### 具体应用例子

- **房价预测**: 根据房屋面积、位置、年限等特征预测房价
- **销售预测**: 根据广告投入、促销活动等预测销售额
- **能源消耗预测**: 根据天气、时间等因素预测能源消耗
- **学生成绩预测**: 根据学习时间、出勤率等预测学生成绩

## 线性回归的假设

线性回归模型基于以下假设：

1. **线性关系**: 输入特征与输出之间存在线性关系
2. **独立性**: 误差项之间相互独立
3. **正态分布**: 误差项服从正态分布
4. ** homoscedasticity（同方差性）**: 误差项的方差在所有输入值上是恒定的
5. **无多重共线性**: 输入特征之间不存在高度相关性

## 线性回归的类型

### 1. 简单线性回归

- 只有一个输入特征
- 模型形式：$y = wx + b$
- 目标是找到最佳的 $w$ 和 $b$，使得预测值与实际值之间的误差最小

### 2. 多元线性回归

- 有多个输入特征
- 模型形式：$y = w_1x_1 + w_2x_2 + ... + w_nx_n + b$
- 目标是找到最佳的权重向量 $\mathbf{w}$ 和偏置 $b$

### 3. 正则化线性回归

- **岭回归（Ridge Regression）**: 在损失函数中添加 L2 正则化项
- **LASSO 回归（Least Absolute Shrinkage and Selection Operator）**: 在损失函数中添加 L1 正则化项
- **弹性网络（Elastic Net）**: 结合 L1 和 L2 正则化

## 线性回归的优缺点

### 优点

- **简单易懂**: 模型形式简单，易于理解和解释
- **计算高效**: 训练速度快，适合处理大规模数据
- **可解释性强**: 权重可以直接反映特征的重要性
- **作为基准模型**: 常被用作其他复杂模型的基准

### 缺点

- **假设线性关系**: 对于非线性关系表现不佳
- **对异常值敏感**: 异常值会显著影响模型性能
- **特征工程要求高**: 需要手动进行特征选择和转换
- **可能存在过拟合**: 当特征数量过多时容易过拟合

## 线性回归的评估指标

常用的线性回归评估指标包括：

1. **均方误差 (MSE)**: $\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$
2. **均方根误差 (RMSE)**: $\sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}$
3. **平均绝对误差 (MAE)**: $\frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|$
4. **R² 评分**: $1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{n}(y_i - \bar{y})^2}$

## 小结

线性回归是一种基础但强大的监督学习算法，用于预测连续值。它假设输入特征与输出之间存在线性关系，并通过最小化预测误差来学习模型参数。线性回归虽然简单，但在许多实际应用中表现良好，是机器学习中最常用的算法之一。
